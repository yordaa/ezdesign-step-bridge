# VCPKG Registry Setup for ezdesign-step-bridge

This repository serves as a vcpkg registry for the `ezd2step` port.

## Structure

```
ezdesign-step-bridge/
├── ports/
│   └── ezd2step/
│       ├── vcpkg.json          # Port metadata
│       ├── portfile.cmake      # Download and install logic
│       └── README.md           # Usage instructions
└── versions/
    ├── baseline.json           # Default version baseline
    └── e-/
        └── ezd2step.json       # Generated by vcpkg x-add-version
```

## Next Steps

### 1. Generate Version File

After committing this structure, run:

```bash
# From repository root
vcpkg --x-builtin-ports-root=./ports --x-builtin-registry-versions-dir=./versions x-add-version ezd2step --all
```

This generates `versions/e-/ezd2step.json` with the git-tree hash.

### 2. Note the Baseline Commit

After committing and generating the version file, note the commit hash for use in EZDesign's `vcpkg-configuration.json`:

```json
{
  "kind": "git",
  "repository": "https://github.com/yordaa/ezdesign-step-bridge",
  "baseline": "<commit_hash_after_setup>",
  "packages": ["ezd2step"]
}
```

### 3. Test Installation

From EZDesign project:

```bash
vcpkg install ezd2step
```

This should:
- Download `ezd2step-1.0.0-macos-arm64.tar.gz` from GitHub Releases
- Extract to `${VCPKG_INSTALLED_DIR}/tools/ezd2step/`
- Optionally copy to `${EZDESIGN_RESOURCES_DIR}/ezd2step/` if variable is set

## Adding New Versions

When a new version is released:

1. Update `ports/ezd2step/vcpkg.json` version
2. Update `versions/baseline.json` baseline version
3. Add platform-specific SHA512 hash to `portfile.cmake`
4. Run `vcpkg x-add-version ezd2step --all` to regenerate version file
5. Commit changes
